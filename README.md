Twitter X Following 关注列表抓取
为了方便自己关注了多少，写的油猴脚本。支持断点抓取保存本地，导出Json与CSV格式；
使用需要打开个人关注页面-正在关注 关掉广告拦截，将页面缩放65%方便抓取更多；保存已经抓到的数据，刷新页面不会清空，断点续抓，对后续新增列表数据不再抓取之前已经抓到的列表进行抓取
缓存存在当前浏览器当前站点，**只保存在本机，不上传任何外部服务器**
